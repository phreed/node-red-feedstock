Low-code programming for event-driven applications

== Description

Node-RED's goal is to enable anyone to build applications that collect, transform and visualize their data;
building flows that can automate their world.
Its low-code nature makes it accessible to users of any background, whether for home automation,
industrial control systems or anything in between.

== Service definition

The recipe installs `service.yaml` into `share/node-red/`.
It is a platform-neutral description of the Node-RED service:
the executable and its arguments,
the account it runs under,
the directories and files to provision,
and the systemd unit overrides to apply.

The program that renders systemd unit files from this description has not been completed yet,
so the file currently ships as data only.
Nothing consumes it at install time.

The definition is included below from its single source of truth rather than copied,
so it cannot drift out of step with the file the package actually ships.
